SCRIPT BUILDER · VALTECH

Recorded actions.
Maintainable tests.

Before One Click, I built Script Builder: a workflow that records manual UI interactions as a JSON manifest, then uses organization-approved Copilot tooling to generate tests and Page Object Model changes.

My role
Solution design & implementation
Constraint
Copilot was the approved AI interface

Capture the user’s intent

Users interact with the application while Script Builder records their clicks in a structured manifest. That record gives Copilot concrete actions to translate into the project’s automation code.

Context at every level

Test-level instructions explain test structure with examples. Page-level instructions describe how to add methods to page classes. Project-level instructions cover repository layout, test locations and data preparation. Together they guide generation toward the existing framework’s conventions.

Explore, measure, adapt

Earlier Playwright MCP experiments generated automated scripts, but exposed reliability limits with smaller models and rapid credit consumption. When organizational security restrictions ruled out MCP, I explored a Playwright CLI approach and built around the approved Copilot workflow.

AI work before One Click

I have explored AI-assisted engineering since ChatGPT’s early release in 2022. Those initial experiments, subsequent browser-automation prototypes and delivered Script Builder work informed One Click; the platform’s June 2025 start was not the beginning of that journey.
